# `INSERT` Commands

**Inserting values to a table**
```sql
INSERT INTO <table-name>
VALUES  (<row1-column1-value>, <row1-column2-value>, ...),
        (<row2-column1-value>, <row2-column2-value>, ...);
```

**Inserting values into specific columns**
```sql
INSERT INTO <table-name> (<column1-name>, <column2-name>, ...)
VALUES  (<row1-column1-value>, <row1-column2-value>, ...),
        (<row2-column1-value>, <row2-column2-value>, ...);
```
