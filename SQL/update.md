# `UPDATE` Commands

**Updating all columns to the same value**
```sql
UPDATE <table-name>
SET <column-name> <new-value>;
```

**Updating a specific column value**
```sql
UPDATE <table-name>
SET <column-name> <new-value>
WHERE <column-name> <operator> <value>;
```

**Updating multiple column values**
```sql
UPDATE <table-name>
SET <column1-name> <new-value>,
    <column2-name> <new-value
WHERE <column-name> <operator> <value>;
```
